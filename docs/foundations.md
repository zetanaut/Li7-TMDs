# Independent mathematical foundations

The `foundations` profile reruns the baseline and requires every check in the checkpoint-2 manifest. It uses exact rational and algebraic arithmetic. The approved source is *Octupole parton structure of spin-3/2 targets* by Brandon B. Le and Dustin Keller, identified in run metadata by the corrected reference SHA-256 7436c7b7dab536999f7caf42af54c5820fa474ca81ab4ff8e4cf15259c9a24ee. The unpublished source file is never read by validation. The derivations below identify its equation labels so signs and normalization can be reviewed without distributing the manuscript.

## Spin and target response

`spin_foundations.py` obtains the $J=3/2$ generators from the ladder rule in descending $J_z$ order. It solves the Cartesian trace conditions for the quadratic and cubic subtraction constants, obtaining $5/4$ and $41/60$ (`eq:Q`, `eq:QO`). It checks every component of the $J$, $Q$, and $O$ trace metrics, cross-rank orthogonality, and reconstruction on all 16 real Hermitian basis matrices. The scalar term for a general matrix $X$ is $\operatorname{Tr}(X)I/4$. A separate construction uses Clebsch–Gordan coefficients in the order $(j_1,j_2,j_3,m_1,m_2,m_3)$ to build the spherical $\tau_{KM}$ (`eq:spherical`). The resulting matrices have unit trace norm and reproduce the Cartesian density inverse. The spherical magnetic label $M$ is distinct from target mass $M_A$ and hard scale $Q$.

`spin_state_foundations.py` calibrates the active rotation against $J_z$, tests a nonzero azimuth and a complex coherence, and compares the matrix preparation with the Cartesian octupole tensor (`eq:rotatedrho`, `eq:Rrotated`). The exact spectrum gives $0\leq\beta_3\leq\sqrt{5}/6$; interior, boundary, and beyond-boundary states are checked. The transverse state retains both LLT and TTT. A real orthonormal rank-three operator basis gives a seven-direction response matrix with determinant $-1400/35937$ (`eq:sevendirections`). Its inverse recovers seven target-response coordinates, while lower-rank response terms cancel in the preparation difference. This is not a separation of fourteen gluon TMDs. Population, ideal 3:4:3 NMR, and $L=1\otimes s=1/2$ projection checks are mathematical model examples (`eq:popinverse`, `eq:NMRmultipoles`, `eq:LSexample`), not a nuclear target-performance prediction.

## Transverse STF and mass

`transverse_foundations.py` constructs rank 0 through 5 by harmonic trace removal from raw Cartesian monomials. A separate complex-helicity formula supplies each component for comparison (`eq:Kn`, `eq:Kcomplex`, `eq:K45`). The symbolic mass $M_A$ is positive and each rank-$n$ tensor contains $M_A^{-n}$. Rank zero is exactly one. The legacy polynomial is the same tensor evaluated on dimensionless $(k_x/M_A,k_y/M_A)$. Trace, dual, norm, homogeneity, right-angle rotation, and scalar/sine contractions are exact polynomial identities. The full coefficient–tensor product is unchanged when $c_{[n]}^{(M_0)}=(M_0/M_A)^n c_{[n]}^{(M_A)}$ (`eq:massconversion`); different orbital ranks receive different factors.

For a worked dyadic example, put $k=(2,1)$, $k^2=5$, and $S=\begin{pmatrix}a&b\\b&-a\end{pmatrix}$. The reference rank-two momentum tensor is $k_2=kk^T-5I/2$. Lowering the target's contracted transverse index with $g_T=-I$, the unnormalized symmetric contraction $-Sk_2-(Sk_2)^T$ is pure trace, so its free-index STF part is zero. Replacing $k_2$ by $kk^T$ gives the explicit STF residual $-5S$ before division by $M_A^2$ (`eq:referenceSTF`, `eq:dyadic_not_STF`). The dyadic negative control fails the null assertion itself.

## Gluon convention conversion

`gluon_dictionary_foundations.py` constructs the lower-spin reference $2\times2$ correlator directly from the displayed tensors of [Boer et al., arXiv:1607.01654v2](https://arxiv.org/html/1607.01654v2), equations 11, 24–25, 36–38, and 95. It lowers contracted Lorentz indices with $g_T=-\delta$ and keeps the reference's unnormalized braces. Projection of the direct reference tensors derives a 36×19-to-18 conversion at an exact point. It agrees with a separately reviewed fixture from `eq:gluon_scalar_dictionary` and `eq:gluon_linear_dictionary`, and the independent minimal Cartesian construction agrees in all matrix entries over symbolic $(x,k_x,k_y,M_A)$ and independent target components. The TT combination and LT shift also appear in the helicity matrix of [Cotogno et al., arXiv:1709.07827v1](https://arxiv.org/html/1709.07827v1), its matrix blocks A–C. The 19 reference labels map onto 18 independent coordinates; the map has rank 18 and kernel generated by a common shift of $f_{1TT}^{\mathrm B}$ and $h_{1TT}^{\perp\mathrm B}$. The LT trace shift, factor two in the LT STF term, TT circular sign, symbolic mass changes, and common $x/2$ normalization are checked. Equal named $S_{LL}$ components and equal Cartesian $T_{zz}$ are separate comparisons; the latter multiplies the two LL coefficients by $3/2$. These are comparisons of tensor conventions, not an identification of spin-one and spin-3/2 hadron distributions.

## Covariants, rank, and recovery

`correlator_foundations.py` keeps explicit source slot tables for the $(f,g,h)$ channels (`eq:Ffull`, `eq:Gfull`, `eq:T0`–`eq:T3`, `eq:H0`–`eq:B3`). Its Cartesian tensor contractions are compared symbolically with a separate helicity and reflection-parity enumeration. Each species has 32 semantic labels; target-rank counts are 2, 6, 10, 14 and channel counts are 8, 8, 16. An unspecified flavor, link, or color class remains explicitly unspecified. Real $64\times32$ maps use rows $(K,m,\mathrm{real/imag},F/G/H_{\mathrm{re}}/H_{\mathrm{im}})$ at $k=(2,1)$, $M_A=3$. A transpose-RREF chooses 32 independent rows. The committed JSON certificates record their exact entries and nonzero determinants. The standalone checker recomputes every selected entry with the helicity construction before checking the determinant; rank alone cannot catch a coordinated sign change. The independent unitary reflection on the joint $8\times8$ parton–target Hermitian space has two four-dimensional eigenspaces, giving the upper bound $4^2+4^2=32$. All explicit covariants lie in this space. A positive state with imaginary coherences confirms target expectation and index order. This is finite-dimensional spanning at generic nonzero momentum, not a QCD factorization proof.

The foundation joint map is an auxiliary coefficient-coordinate convention. The physical source-index matrix equals one half its parton partial transpose; this invertible row-coordinate change preserves the 64-by-32 coefficient rank, but can change the rank and positivity of an individual 8-by-8 matrix. The committed minor remains an auxiliary-coordinate rank witness, not a physical positivity certificate. See the [source/spectral index derivation](convention-closure.md).

For coefficient recovery, `projector_foundations.py` uses the scalar angular projector and the separate low/high quark and gluon branch inverses (`eq:scalarinverse`, `eq:qinverse`, `eq:ginverse`). Eight-point Fourier quadrature equals the angular integral exactly for the harmonics present here. It recovers every unit coefficient and a mixed 32-coefficient vector. An independent exact inverse of the selected Cartesian rows returns the same vector. The inverse projectors require nonzero momentum when their orbital prefactors vanish; the forward correlator remains defined at zero momentum.

## Reproduce and interpret

```sh
python scripts/run_validation.py --profile foundations --output-root validation_runs
python scripts/check_foundation_certificates.py
python scripts/update_report_summary.py --run-dir validation_runs/RUN --output docs/generated-foundations.md
python scripts/run_validation.py --profile full --output-root validation_runs
```

Replace `RUN` with the run directory printed by the first command. A foundations PASS requires the complete baseline, all exact foundations, certificate checks, and injected failure tests. The later cumulative profiles now execute the declared finite process and limit checks. A `full` profile checks the resolved [physical Born convention](convention-closure.md) and retains the pre-correction mismatch as a negative regression. A scientific PASS grants no standing deployment permission; Pages requires separate authorization for the exact commit. A failed identity, altered certificate, omitted required check, or run-ID mismatch prevents a passing summary.

Run records distinguish unique claims, component cases, independent comparisons, rank witnesses, numerical corroborations, negative controls, and software regressions. The Cartesian and helicity routes share SymPy arithmetic and the stated index/mass conventions; their tensor generation differs. The parity-space bound uses a separate joint-spin reflection. Analytic projectors use published branch formulas, whereas the linear-map recovery uses Cartesian rows. The dictionary's reference side is built from original tensors, while its minimal side uses the present correlator. The separate certificate checker recomputes entries from helicity formulas but shares the reviewed semantic label order and conventions.
