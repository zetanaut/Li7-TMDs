# Generated result summary

This page is regenerated from a complete, same-revision `full` validation run by `scripts/update_report_summary.py`. The tracked copy contains no saved PASS totals or Born values, because those must be read from the run being published.

To generate it locally, run `python scripts/run_validation.py --profile full --output-root validation_runs` and pass the printed run directory to `python scripts/update_report_summary.py --run-dir RUN --output docs/generated-results.md`. The publication workflow performs the same sequence and checks the resulting site before any upload. The current publication authorization flag is false.

The corrected physical-helicity convention and historical wrong-order negative control are described in the [ordered-current note](convention-closure.md).
